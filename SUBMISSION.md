## November work / notes

This is a new project created on November 24, 2026; no project code existed before November 1. It compares exported Cashu bearer-token backups entirely offline. A shared zero-dependency JavaScript parser powers a local browser interface and Node CLI, supports NUT-00 cashuA/cashuB, detects repeated proofs across encodings, separates mints and units, and excludes inconsistent copies from deduplicated face values.

All results are explicitly unverified face values, not a wallet balance or a signature/spent-state check. No tokens, secrets, signatures, witnesses or memos enter exported reports. The app has no network requests, persistent storage, analytics or clipboard reading. Browser/OS memory cannot be securely erased.

Original implementation was developed with an AI coding assistant. Tests use only public NUT-00 examples and synthetic tokens. Public specification examples retain the upstream MIT license; the original project is MIT licensed.
